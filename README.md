# EchoMind

AI-powered sentiment and emotion analysis project.

## Project Structure

- `src/core/` → Core sentiment analysis logic
- `src/web/` → Web application and server files
- `data/` → CSV datasets and generated summaries
- `setup/` → Environment and dependency setup scripts
- `docs/` → Documentation

## Run Project

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the web app:

```bash
python src/web/app.py
```

Run batch analysis:

```bash
python src/core/batch_analyze.py
```
